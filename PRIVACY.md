# 隱私權政策 / Privacy Policy

> 本文件為 SPCRK 的隱私權政策，同時提供繁體中文與英文版本。
> This document is the privacy policy for SPCRK, provided in both Traditional Chinese and English.

## 繁體中文

### 一、資料收集

**SPCRK 不收集、不儲存、不傳輸任何使用者個人資料。**

- 本應用程式的所有操作皆在**使用者手機本地端**運行，無需連接任何後端伺服器。
- 應用程式**不會**收集您的姓名、電子郵件、電話號碼、裝置識別碼、位置、通訊錄、相簿內容或其他任何個人識別資訊。
- 應用程式**不會**使用任何分析、追蹤或廣告 SDK。

### 二、資料儲存

- 您在使用本應用程式時產生的任何資料（例如設定、對話紀錄、下載歷史等），皆僅儲存在**您自己的裝置上**。
- 本應用程式**不會**上傳、備份或同步您的資料到任何雲端或第三方伺服器。

### 三、權限

- 應用程式可能要求特定權限（例如存取檔案或相機），僅用於提供您主動使用的功能。
- 這些權限**僅在您主動操作時**才會被使用，應用程式不會在背景存取您的敏感資料。

### 四、第三方服務

- 本應用程式可能連線至您自行配置的第三方服務（例如 AI 模型 API、MCP 伺服器），以執行您明確要求的功能。
- 任何與第三方服務之間的資料傳輸，均由您主動發起並由您自行承擔責任，與本應用程式開發者無關。

### 五、免責聲明

- **本應用程式所有操作皆與開發者無關。** 開發者不對您在使用本應用程式過程中，因任何原因（包括但不限於：您設定或連線的第三方服務、您自行上傳或處理的資料、裝置或系統因素）所導致的任何直接或間接損失負責。
- 本應用程式以「現況」提供，不提供任何明示或默示之保證。

### 六、政策變更

- 若本隱私權政策有任何變更，將更新於此文件並於本儲存庫發布。

## English

### 1. Data Collection

**SPCRK does not collect, store, or transmit any personal user data.**

- All operations of this application are performed **locally on the user's device**, without requiring any connection to a backend server.
- The application **does not** collect your name, email address, phone number, device identifiers, location, contacts, photo library contents, or any other personally identifiable information.
- The application **does not** use any analytics, tracking, or advertising SDKs.

### 2. Data Storage

- Any data you generate while using this application (such as settings, conversation history, download history, etc.) is stored **only on your own device**.
- The application **does not** upload, back up, or sync your data to any cloud or third-party server.

### 3. Permissions

- The application may request certain permissions (such as file access or camera) solely to provide features you actively use.
- These permissions are used **only when you actively perform an operation**; the application does not access your sensitive data in the background.

- If this privacy policy changes, it will be updated in this document and published in this repository.
