# Sparck 灵愿

[English](./README.md) | 中文

专为 Android 手机打造的多功能超级应用
> ***当前为预览版***

## 主要功能

1. 视频下载
2. 多 **AI** 提供商支持：OpenAI、Gemini、Anthropic 等
3. 支持调用 MCP、Skill 功能

## 技术栈

1. 开发语言：Kotlin
2. UI 框架：Jetpack Compose
3. 数据库：Room Database
4. 网络库：OkHttp

> 最低支持 **Android 8**（API 26）
