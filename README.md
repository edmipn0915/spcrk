# Sparck

[中文](./README-zh.md) | English

An all-in-one super app built for Android.
> ***Currently in preview***

## Features

1. Video download
2. Multiple **AI** providers: OpenAI, Gemini, Anthropic, and more
3. MCP and Skill integration

## Tech Stack

1. Language: Kotlin
2. UI: Jetpack Compose
3. Database: Room Database
4. Networking: OkHttp

> Requires **Android 8** (API 26) or above
